**UAT-1** ✅ — 正确凭证连接成功并列出未读邮件数；凭证错误时弹确认栏「邮箱登录失败，请检查 config.yaml 中的凭证」，本次运行安全终止，不修改任何邮件状态。

## ✅ FR-2 未读邮件拉取与防重 → Phase 2

- [x] 每次运行拉取收件箱全部**未读**邮件；
- [x] 处理前对照输出目录 `processed_emails.json`（已处理邮件 Message-ID），已处理直接跳过；
- [x] 单封**处理成功后**按固定顺序执行：① IMAP 标记已读 → ② Message-ID 写入 processed_emails.json；

**UAT-2** ✅ — 同一封邮件不进入两份报告；人为中断后重跑，未完成邮件能被重新处理。
